WebOS wrapper for TorrServer binary.

Autostart of server is enabled on first launch (for rooted devices, Homebrew channel required). Reinstall app to disable autostart feature.

A shell for running TorrServer on webOS.

Autostart when TV is turned on is activated when the application is first launched (Homebrew channel startup automation is also required) - the server starts and runs in the background. To disable autostart, delete the application, install it again and launch it.
