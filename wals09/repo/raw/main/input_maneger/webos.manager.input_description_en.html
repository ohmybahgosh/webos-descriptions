The login manager is designed to assign applications to login. The current version allows you to manage login settings for the ott play application (ID: com.ottplay.app) and its modifications DRM-play (ID:com.ott.drm) and Ott-FOSS (ID:com.ottplay.foss)

Attention: On WebOS below version 4.0, operation is not guaranteed.After installation, reboot the TV. Before rebooting, make sure that FAST BOOT + is disabled in the GENERAL section in the settings
